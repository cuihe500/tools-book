# 工具书章节

本仓库是一本个人工具速查书（Astro Starlight，部署在 https://tools-docs.bytcloud.org ）。
一个工具一个文件：`src/content/docs/<工具名>.md`。侧边栏和搜索索引自动生成，**不需要改任何其他文件**。

## 流程

1. **核对资料**：写之前用 fetch_content / web_search 查该工具的官方文档（尤其是 keybindings、
   cheatsheet、commands 列表），校准快捷键和命令的准确性。宁可少写，不写没核实的键位。
2. **写章节**：新建或修改 `src/content/docs/<工具名>.md`（文件名小写）。
3. **构建验证**：`npm run build`，失败必须修好再进下一步。
4. **提交推送**：`git add -A && git commit -m "<简短中文说明>" && git push`。
   push 后 GitHub Actions 自动部署，无需其他操作。

## 章节风格

这是"忘了就来翻一下"的快速查找书，**不是标准化文档，没有固定模板**。要求只有这些：

- frontmatter 必须有 `title: <工具名>`，建议加一行 `description`（会进搜索索引）。
- 开头一两段自然叙述：这工具是干什么的、有什么特点、哪里最好用。
- 之后按需组织：快捷键/命令多就分几个小节列表格，少就一个表甚至几行文字。
  表格两列（键/命令 → 作用）即可。
- 中文描述动作（"撤销"、"变基"、"暂存"），这样中文搜索才搜得到。
- 结尾可放"备查"：官方完整文档链接、配置文件路径。
- 篇幅以"常用够查"为准，不追求穷举，完整表交给官方链接。

风格样板看 `src/content/docs/lazygit.md`。
