终端里的 Git TUI。左边五个侧栏面板（状态 / 文件 / 分支 / 提交 / 贮藏），右边主视图显示详情。绝大部分 git 操作都是单键：暂存按空格、提交按 `c`、拉取 `p` 推送 `P`。它最爽的两件事：**行级暂存**（进文件里按空格挑行）和**傻瓜式交互 rebase**（在提交列表里直接按键挪、squash、改消息）。

记不住键就在任意界面按 `?`，会弹出当前面板的全部快捷键，这本身就是内置速查表。

## 全局

| 键 | 作用 |
|---|---|
| `?` | 打开当前面板的按键菜单 |
| `1`-`5` / `h` `l` | 在侧栏面板间跳转 |
| `Enter` / `Esc` | 进入 / 返回 |
| `p` / `P` | 拉取 / 推送 |
| `z` / `Z` | 撤销 / 重做（基于 reflog，只管提交不管工作区） |
| `/` | 搜索 / 过滤当前列表 |
| `[` `]` | 切换面板内的标签页 |
| `+` / `_` | 循环屏幕模式（正常/半屏/全屏） |
| `:` | 执行任意 shell 命令 |
| `m` | 合并/变基进行中的选项（继续、中止、跳过） |
| `@` | 命令日志菜单（看 lazygit 到底跑了什么 git 命令） |
| `ctrl+r` | 切换最近的仓库 |
| `R` | 刷新状态 |
| `q` | 退出 |

## 文件面板（暂存与提交）

| 键 | 作用 |
|---|---|
| `Space` | 暂存 / 取消暂存选中文件 |
| `a` | 全部暂存 / 取消暂存 |
| `Enter` | 进入文件挑行暂存（行级暂存视图） |
| `c` | 提交 |
| `w` | 提交但跳过 pre-commit 钩子 |
| `C` | 用 git 配置的编辑器写提交信息 |
| `A` | 修补（amend）最后一次提交 |
| `ctrl+f` | 自动找到当前改动应该 fixup 的提交 |
| `d` | 放弃改动（弹出选项） |
| `i` | 加入 .gitignore |
| `s` / `S` | 贮藏全部 / 打开贮藏选项（只藏已暂存等） |
| `f` | fetch |
| `D` | 工作树重置选项（含清空） |
| `` ` `` | 文件列表在平铺 / 树形之间切换 |

### 行级暂存视图（Enter 进入后）

| 键 | 作用 |
|---|---|
| `Space` | 暂存 / 取消暂存选中行或块 |
| `v` | 拖选多行 |
| `a` | 逐行 / 按块选择切换 |
| `d` | 丢弃选中改动 |
| `Tab` | 在未暂存 / 已暂存两侧切换 |
| `E` | 把选中块丢进外部编辑器改 |
| `c` | 直接从这里提交 |

## 分支面板

| 键 | 作用 |
|---|---|
| `Space` | 检出选中分支 |
| `n` | 新建分支 |
| `c` | 按名字检出（输 `-` 回上一个分支） |
| `-` | 检出上一个分支 |
| `d` | 删除（本地/远程选项） |
| `M` | 把选中分支合并进当前分支 |
| `r` | 把当前分支 rebase 到选中分支上 |
| `f` | 从上游快进 |
| `R` | 重命名 |
| `u` | 上游选项（设置/取消/重置到上游） |
| `T` | 建标签 |
| `o` | 创建 Pull Request |

## 提交面板（改历史）

选中某个提交后：

| 键 | 作用 |
|---|---|
| `r` / `R` | 改提交信息（`R` 用编辑器） |
| `s` | squash 进下面的提交 |
| `f` | fixup 进下面的提交（丢弃本条信息） |
| `d` | 删除提交 |
| `e` / `i` | 从此提交 / 从分支头开始交互式变基 |
| `ctrl+j` / `ctrl+k` | 把提交下移 / 上移 |
| `A` | 把已暂存的改动 amend 进选中提交 |
| `F` | 为选中提交创建 fixup 提交 |
| `S` | 自动压缩所有 fixup!（autosquash） |
| `C` / `V` | 复制提交（拣选）/ 粘贴到当前分支（cherry-pick） |
| `t` | revert 选中提交 |
| `T` | 给提交打标签 |
| `n` | 从提交建新分支 |
| `g` | 重置选项（soft / mixed / hard） |
| `y` | 复制提交属性（hash、URL、diff、消息） |
| `o` | 在浏览器打开提交 |

## 贮藏面板

| 键 | 作用 |
|---|---|
| `Space` | 应用贮藏 |
| `g` | 应用并删除（pop） |
| `d` | 删除贮藏 |
| `n` | 从贮藏建新分支 |
| `r` | 重命名贮藏 |

## 合并冲突（进入冲突文件后）

| 键 | 作用 |
|---|---|
| `h` / `l` | 上一个 / 下一个冲突 |
| `k` / `j` | 选上半块 / 下半块 |
| `Space` | 采用选中块 |
| `b` | 两块都要 |
| `z` | 撤销上一次冲突解决 |
| `e` | 用外部编辑器打开 |
